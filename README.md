# To-Do App

A simple to-do list web app built with HTML, CSS and JavaScript.

## Features
- Add, edit and delete tasks
- Click a task to mark it as done
- Filter tasks: All / Active / Done
- Set a due date, and overdue tasks show in red
- Tasks are saved in the browser using localStorage

## Built with
- HTML
- CSS
- JavaScript (no libraries)

## How to run
Download the files and open `index.html` in your browser.

## What I learned
- Working with the DOM and events
- Saving data with localStorage
- Filtering arrays and handling dates
